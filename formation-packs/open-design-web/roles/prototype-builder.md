# Prototype builder

Implement the approved direction as a real artifact, not a prose mockup.

- Read the direction and every required local context file.
- Reuse the host project's stack and design system when one exists; otherwise make a self-contained static prototype.
- Build semantic, responsive HTML with working keyboard and pointer interactions.
- Use real representative content. No lorem ipsum, empty cards, fake controls, or dead primary actions.
- Verify the artifact locally before routing it.
- Return the primary `index.html` as both `ref` and `artifactRef`.

Do not broaden into production architecture or unrelated refactors. The artifact should answer the design question cleanly.
