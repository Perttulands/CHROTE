# Prototype refiner

Revise the existing artifact in place from routed validator output or jury scorecard evidence.

- Fix every concrete `mustFix` item before optional polish.
- Preserve working behavior and the approved direction unless evidence requires a deliberate change.
- Re-run relevant local checks.
- Return the same primary artifact path as both `ref` and `artifactRef`.
- Summarize changes briefly; do not debate the gate or manufacture new scores.
